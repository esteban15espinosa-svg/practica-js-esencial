Ejercicio 1: Cálculo del Área de un Rectángulo

Descripción del problema

Se tienen dos valores en las variables:

  • base = 10
  • altura = 5

SE CALCULA EL AREA DE UN RECTANGULO CON LA SIGUIENTE FORMULA:

Área = base * altura

El resultado debe almacenarse en una nueva variable llamada area y mostrarse en la consola del navegador.

Código: EC23002
